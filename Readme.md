# Overloaded Tinkering Lib

---

This mod is a library that separates the following features from TiCEX to allow more people to create more stylish Tinkers' Construct tools:
- Shader registration for tools, armor, and trims
- Special geometry for models that changes color depending on the material used for the tool
- A system for rendering additional custom models for armor
- Integrated energy storage supporting capacities of Integer or larger
- Two new modifier hooks: Critical and damage source modification
